# Code de conduite

## L'essentiel

MyHousehold est un projet d'entraide autour d'un besoin très ordinaire : s'organiser
à plusieurs sous le même toit. On y participe comme on se comporterait chez
quelqu'un — avec considération.

## Attendu

- Parler aux autres avec respect, y compris en désaccord.
- Critiquer le code, les idées et les choix techniques — jamais les personnes.
- Accepter qu'un contributeur débutant pose des questions élémentaires. Tout le monde
  a commencé là.
- Accepter une décision qui ne va pas dans son sens, une fois la discussion tenue.

## Inacceptable

- Insultes, attaques personnelles, propos discriminatoires.
- Harcèlement, public ou privé.
- Publication d'informations personnelles sans autorisation.
- Mépris affiché pour le niveau technique d'autrui.

## Portée

Ce code s'applique aux issues, pull requests, discussions et à tout espace où l'on se
présente comme participant au projet.

## Signalement

Contactez le mainteneur en privé via GitHub ([@overline090](https://github.com/overline090)).
Les signalements sont traités avec discrétion. Un signalement de bonne foi n'exposera
jamais son auteur à des représailles.

## Mesures

Selon la gravité : rappel privé, avertissement public, puis exclusion du projet.
Le mainteneur décide, et explique sa décision aux personnes concernées.

## Un mot sur le ton

Ce code est court volontairement. Il n'existe pas pour légiférer, mais pour qu'il y
ait une référence écrite le jour où ce sera nécessaire. Dans l'immense majorité des
cas, « on se parle correctement » suffit.
